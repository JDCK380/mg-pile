连接充电桩

连接条件与认证说明

使用 Windows 或 Android 的 Chrome，在 HTTPS 或 localhost 中打开。服务 FFF0，指令 FFF3，VIN FFF6；监听 FFF4 / FFF5 / FFF9。VIN 校验失败会停止发送控制指令。桩号有填写时，系统信息返回的桩号必须匹配。只拥有 UUID 不代表已经认证。

本地蓝牙连接 · 1.0.1

未到预约时间，立即充电？

将关闭充电桩的预约，确认关闭后发送启动指令。原预约不会自动恢复；下次需要重新设置。

如果车辆本身设置了预约，桩端不能代替车辆解除预约；部分桩也可能需要重新插枪。
